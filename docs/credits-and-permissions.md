## Status values

- `Verified`: explicit redistribution permission or compatible license confirmed
- `Credit required`: allowed with specified attribution
- `Private testing only`: usable locally but not publishable
- `Unknown`: origin or permission not yet established
- `Replace`: must be recreated or removed before release

## Release gate

Every shipped model, texture, animation, sound, effect, script, icon, and localization asset must have a non-unknown status. Assets marked private testing only may not appear in a public release package.
